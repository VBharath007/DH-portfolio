## 3. Technology Stack

- **Framework**: Next.js 16 (App Router, Turbopack, React 19)
- **Language**: TypeScript (Strict typing across components, utilities, and datasets)
- **Styling**: Organized Global CSS + Tailwind CSS v4 + Google Fonts (`Cinzel` & `Inter`)
- **Icons**: Lucide React + Clean inline brand SVGs
- **Animation**: Framer Motion (Cinematic intro, CEO reveal, interactive cursor blueprint spotlight)

## 5. Development & Production Commands

```bash
# Install dependencies
npm install

# Run development server
npm run dev

# Run TypeScript checks
npx tsc --noEmit

# Run ESLint validation
npm run lint

# Build production bundle
npm run build

# Start production server
npm run start
```
